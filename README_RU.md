# Шаблон HobDrive Dashkit

[English](README.md) | [Русский](README_RU.md) | [Español](README_ES.md)

Это репозиторий-шаблон для создания ваших собственных пользовательских дашкитов для HobDrive.

## Начало работы

1. **Клонируйте этот репозиторий:** 
   Клонируйте его с помощью кнопки "Fork" на GitHub.
   Переименуйте репозиторий напрямую в GitHub, если хотите.

   Или через командную строку:
   ```bash
   git clone https://github.com/hobdrive/template-dashkits.git my-dashkit
   cd my-dashkit
   ```

2. **Переименуйте папку template в желаемое имя панели**
   ```bash
   cd community
   mv template my-dashkit-name
   cd my-dashkit-name
   ```

3. **Отредактируйте файл community/my-dashkit-name/info.json:**
   - Обновите поля `name`, `description` и `author`
   - Установите желаемый номер версии

4. **Настройте свой макет:**
   - Отредактируйте `user.layout` для создания пользовательского дизайна панели
   - Добавьте пользовательские изображения в папку `images/`

5. **Протестируйте свой дашкит:**
   - Отправьте свой репозиторий на GitHub
   - В **Hobdrive** выберите "Manage DashKits"
   - Измените `Repo name` на идентификатор вашего репозитория (`your-login/repo-name`)
   - Измените `Branch` при необходимости
   - Нажмите `Update` - это загрузит ваш репозиторий
   - Нажмите кнопку `Install` на вашем DashKit
  
6. **Обновите свой дашкит:**
   - После установки вы можете напрямую обновить уже установленную панель.

## Что включено

- **community/template/** - Простой рабочий дашкит с базовым макетом
- **info.json** - Файл метаданных для вашего дашкита
- **user.layout** - Основной файл макета, где вы определяете экраны панели
- **images/** - Папка для пользовательских изображений и графики

## Советы

1. **Начните с простого:** Начните с включенного шаблона и постепенно добавляйте сложность
2. **Часто тестируйте:** Тестируйте свой макет в HobDrive после каждого изменения
3. **Используйте условия:** Используйте атрибуты `if` для отображения элементов только при наличии датчиков
4. **Сначала предпросмотр:** Шаблон включает рабочий пример, который вы можете изменить
5. **Оптимизация изображений:** Держите файлы изображений небольшими для лучшей производительности
6. **Несколько разделов:** Вы можете создать несколько экранов панели в одном файле макета

## Структура файлов

```
my-dashkit/
├── README.md (этот файл)
├── LAYOUT_SPEC.md (полный справочник синтаксиса)
└── community/
    └── your-dashkit-name/
        ├── info.json (метаданные дашкита)
        ├── user.layout (макет вашей панели)
        ├── README.md (опционально: опишите свой дашкит)
        └── images/ (опционально: пользовательская графика)
```

## Публикация вашего дашкита

Когда вы готовы поделиться своим дашкитом:

1. Обновите README в папке вашего дашкита со скриншотами и описанием
2. Убедитесь, что в вашем info.json есть точная информация
3. Рассмотрите возможность отправки pull request в основной репозиторий hobdrive-dashkits
4. Поделитесь с сообществом!
